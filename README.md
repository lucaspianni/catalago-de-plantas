## 📖 Sobre o projeto

O **Catálogo de Plantas** é uma aplicação web desenvolvida para apresentar informações de forma organizada e visualmente agradável.

O projeto foi desenvolvido utilizando **Next.js, React e TypeScript**, com estilização em **Tailwind CSS** e integração com **Supabase**.

A aplicação foi preparada para ser publicada diretamente na web utilizando **GitHub Pages** e **GitHub Actions**.

## ⚙️ Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/lucaspianni/catalago-de-plantas.git
```

### 2. Entre na pasta do projeto

```bash
cd catalago-de-plantas/project
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

### 5. Abra no navegador

```text
http://localhost:3000
```

## 🌐 Deploy

O projeto está configurado para ser publicado automaticamente através do **GitHub Actions**.

A cada atualização enviada para a branch `main`, o workflow realiza o processo de:

```text
Código → Instalação das dependências → Build → Deploy → GitHub Pages
```
